# 博客封面图 AI 绘画提示词

## 📍 图片位置和用途说明

### 图片存储位置
所有博客封面图应保存在：`public/images/blog/`

### 图片用途
每张封面图会在以下位置使用：
1. **博客列表页** (`/blog`) - 卡片缩略图，高度 192px，宽度响应式
2. **文章详情页** - 文章顶部封面，高度 256-384px（响应式），宽度全屏
3. **相关文章** - 小缩略图，高度 128px，宽度响应式
4. **社交媒体分享** - Open Graph 图片（1200x630px 推荐）

### 重要提示
- **使用同一张图片**：所有位置使用同一个 `coverImage` 字段
- **构图要求**：重要元素应放在**画面中心区域**，因为图片会被裁剪成不同尺寸
- **最佳尺寸**：建议生成 **1200x630px (16:9)** 的图片，系统会自动裁剪适应不同显示场景

## 使用建议

### 推荐的 AI 绘画工具：
1. **Midjourney** - 质量高，风格多样
2. **DALL-E 3** - 理解能力强，细节丰富
3. **Stable Diffusion** - 免费开源，可本地运行
4. **Adobe Firefly** - 商业使用友好

### 通用参数建议：
- **尺寸：** 1200x630px (16:9 比例) - **必须**
- **构图：** 重要元素居中，避免边缘放置关键内容（会被裁剪）
- **风格：** Modern, professional, minimalist, tech blog style
- **质量：** High resolution, detailed, clean design
- **色调：** 根据主题选择（蓝色系适合隐私/技术，橙色适合社交媒体）

### 构图注意事项：
由于同一张图片会在多个位置以不同尺寸显示，请确保：
- ✅ 主要视觉元素（如设备、图标）放在画面**中心区域**
- ✅ 避免在图片边缘放置重要文字或图标
- ✅ 背景设计应简洁，即使被裁剪也能保持美观
- ✅ 使用 16:9 横向构图，适合各种显示场景

### 优化技巧：
1. 如果生成结果不理想，可以添加：
   - "vibrant colors"（鲜艳色彩）
   - "soft shadows"（柔和阴影）
   - "professional lighting"（专业光照）
   - "clean background"（简洁背景）

2. 如果需要特定风格，可以添加：
   - "flat design"（扁平化设计）
   - "isometric illustration"（等距插画）
   - "3D render"（3D渲染）
   - "photorealistic"（照片级真实）

3. 多次迭代：
   - 先生成基础版本
   - 根据结果调整提示词
   - 可以组合多个提示词的结果

### 后期处理建议：
生成图片后，建议：
1. 检查文字是否清晰（序列号、快门计数等）
2. 调整对比度和饱和度
3. 确保符合 1200x630px (16:9) 尺寸
4. 验证中心区域构图：裁剪成 192px 高度（列表页）和 128px 高度（相关文章）时，主要元素是否仍然可见
5. 压缩到合适大小（<500KB）以优化网页加载速度
6. 保存到 `public/images/blog/` 目录

### 图片显示尺寸参考：
- **博客列表页卡片**：高度 192px，宽度响应式（1-3列布局）
- **文章详情页封面**：高度 256px（移动端）或 384px（桌面端），宽度全屏
- **相关文章缩略图**：高度 128px，宽度响应式
- **社交媒体分享**：1200x630px（完整显示）
