# 统计数字 UI 方案建议

## 方案一：简洁徽章式（推荐）⭐
**位置**：上传区域内部，文字下方  
**样式**：两个小徽章并排显示，数字突出，背景色淡雅

```
┌─────────────────────────────────┐
│         [图标]                   │
│    拖放图片到这里                │
│    或点击上传                    │
│    支持 JPG、PNG、WebP           │
│                                 │
│  ┌─────────┐  ┌─────────┐      │
│  │ 1,234   │  │ 2.5 GB  │      │
│  │ 张图片  │  │ 已处理  │      │
│  └─────────┘  └─────────┘      │
└─────────────────────────────────┘
```

**优点**：
- 简洁不干扰
- 视觉平衡
- 易于阅读

---

## 方案二：信息卡片式
**位置**：上传区域上方，独立卡片  
**样式**：横向卡片，两个统计数字并排，带图标

```
┌─────────────────────────────────┐
│ 📊 我们已为 1,234 张图片清除    │
│    EXIF，总共处理 2.5 GB        │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│         [上传区域]               │
└─────────────────────────────────┘
```

**优点**：
- 信息突出
- 可添加图标增强视觉效果
- 独立区域，不占用上传区域空间

---

## 方案三：内嵌文字式
**位置**：上传区域内部，替换或补充现有文字  
**样式**：在"支持 JPG、PNG、WebP"下方添加一行统计文字

```
┌─────────────────────────────────┐
│         [图标]                   │
│    拖放图片到这里                │
│    或点击上传                    │
│    支持 JPG、PNG、WebP           │
│                                 │
│  ✨ 已为 1,234 张图片清除 EXIF  │
│     总共处理 2.5 GB              │
└─────────────────────────────────┘
```

**优点**：
- 自然融入
- 不增加额外视觉元素
- 保持简洁

---

## 方案四：浮动标签式
**位置**：上传区域右上角，小标签  
**样式**：角标式显示，数字突出

```
┌─────────────────────────────────┐
│  [1,234 张 | 2.5 GB]        ┌─┐│
│         [图标]               │ ││
│    拖放图片到这里            └─┘│
│    或点击上传                    │
│    支持 JPG、PNG、WebP           │
└─────────────────────────────────┘
```

**优点**：
- 不占用主要内容区域
- 现代感强
- 适合移动端

---

## 方案五：底部横幅式
**位置**：上传区域下方，独立横幅  
**样式**：浅色背景横幅，居中显示统计

```
┌─────────────────────────────────┐
│         [上传区域]               │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│  📊 已处理 1,234 张图片 · 2.5 GB │
└─────────────────────────────────┘
```

**优点**：
- 清晰分离
- 可添加更多信息
- 易于扩展

## 建议

**首选：方案一（简洁徽章式）**
- 平衡了信息展示和视觉干扰
- 实现简单
- 适配性好

**备选：方案三（内嵌文字式）**
- 最简洁
- 自然融入现有设计
- 适合极简风格
