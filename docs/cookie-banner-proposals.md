# Cookies 横幅设计方案

## 项目背景
- **设计风格**: Neo-Brutalism（野兽派）- 粗边框、硬阴影、大写字体
- **技术栈**: Next.js 14 + next-intl（国际化）
- **Cookie 用途**: Google AdSense 广告
- **合规要求**: GDPR、CCPA 等隐私法规

---

## 方案一：底部固定横幅（推荐）⭐

### 设计特点
- **位置**: 页面底部固定，不遮挡主要内容
- **样式**: 全宽横幅，粗边框，硬阴影
- **交互**: 滑入动画，接受后滑出隐藏
- **按钮**: "接受全部" + "拒绝" + "自定义"（可选）

### 优点
- ✅ 符合 GDPR 最佳实践
- ✅ 不干扰用户浏览体验
- ✅ 移动端友好
- ✅ 实现简单

### 视觉效果
```
┌─────────────────────────────────────────────────┐
│  🍪 WE USE COOKIES                              │
│  We use cookies to show you relevant ads.      │
│  [ACCEPT ALL] [REJECT] [CUSTOMIZE]             │
└─────────────────────────────────────────────────┘
```

### 实现要点
- `position: fixed; bottom: 0;`
- `z-index: 1000`
- 滑入动画：`transform: translateY(0)`
- 接受后保存到 `localStorage`

## 方案二：顶部固定横幅

### 设计特点
- **位置**: 页面顶部，Navbar 下方
- **样式**: 全宽横幅，黄色背景（#FFD93D）
- **交互**: 向下滑入，接受后向上滑出
- **按钮**: "接受" + "拒绝" + "了解更多"链接

### 优点
- ✅ 更显眼，用户第一时间看到
- ✅ 符合某些地区的合规要求
- ✅ 可以固定在顶部，滚动时保持可见

### 缺点
- ⚠️ 可能遮挡部分内容
- ⚠️ 需要调整 Navbar 的 `pt-16` 间距

### 视觉效果
```
┌─────────────────────────────────────────────────┐
│  🍪 COOKIES NOTICE                              │
│  Accept cookies to see personalized ads.       │
│  [ACCEPT] [REJECT] [Learn More →]              │
└─────────────────────────────────────────────────┘
```

## 方案三：右下角浮动卡片

### 设计特点
- **位置**: 右下角浮动，不遮挡主要内容
- **样式**: 紧凑卡片，粗边框，硬阴影
- **交互**: 从右下角滑入，可关闭按钮
- **按钮**: "接受" + "拒绝" + "×" 关闭

### 优点
- ✅ 不占用全宽，视觉干扰小
- ✅ 现代感强，类似通知样式
- ✅ 可以添加关闭按钮

### 缺点
- ⚠️ 移动端可能显示不全
- ⚠️ 需要响应式调整大小

### 视觉效果
```
                    ┌──────────────┐
                    │ 🍪 COOKIES   │
                    │ We use       │
                    │ cookies for  │
                    │ ads.         │
                    │ [ACCEPT] [×] │
                    └──────────────┘
```

## 方案四：全屏模态框（首次访问）

### 设计特点
- **位置**: 全屏覆盖，居中显示
- **样式**: 大卡片，粗边框，硬阴影
- **交互**: 淡入动画，必须选择才能继续
- **按钮**: "接受全部" + "仅必要" + "自定义设置"

### 优点
- ✅ 最符合 GDPR 严格合规
- ✅ 用户必须做出选择
- ✅ 可以展示详细的 Cookie 分类

### 缺点
- ⚠️ 用户体验可能过于强制
- ⚠️ 可能影响转化率

### 视觉效果

│         │   🍪 COOKIE CONSENT   │          │

## 技术实现建议

### 组件结构
```
src/components/
  └── CookieBanner.tsx          # 主横幅组件
  └── CookieSettings.tsx        # Cookie 设置面板（可选）
  └── hooks/
      └── useCookieConsent.ts   # Cookie 同意状态管理
```

### 状态管理
```typescript
type CookieConsent = {
  accepted: boolean;
  timestamp: number;
  preferences?: {
    essential: boolean;
    analytics: boolean;
    advertising: boolean;
  };
}
```

### localStorage Key
```typescript
const COOKIE_CONSENT_KEY = 'cookie-consent';
```

### AdSense 集成
```typescript
// 只有在用户接受广告 Cookie 后才加载 AdSense
if (consent.preferences?.advertising) {
  // 加载 AdSense 脚本
}
```

## 设计规范（野兽派风格）

### 颜色
- **背景**: 白色 `bg-white`
- **边框**: 黑色 `border-4 border-black`
- **阴影**: `shadow-brutal-lg` (6px 6px 0px 0px #000)
- **强调色**: 黄色 `#FFD93D`（可选）

### 字体
- **标题**: `font-black uppercase`
- **正文**: `font-bold`
- **按钮**: `font-black uppercase`

### 动画
- **滑入**: `transform: translateY(0)` from `translateY(100%)`
- **悬停**: `hover-brutal` 效果
- **过渡**: `transition-all duration-300`
