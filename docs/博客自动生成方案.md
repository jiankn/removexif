
## 自动化方案概览
- **输入**：一份主语言 Markdown（含最少 frontmatter：`title/description/tags/date/coverSource`）。
- **AI 翻译层**：CLI 读取原文后串行/并行调用 DeepSeek API（如 `deepseek-chat`）。把译文与 frontmatter 中的 `locale` 元信息组合成 8 份文本。
- **内容落地层**：脚本将译文写入 `src/content/posts/<locale>/<slug>.md`，slug 由 CLI 统一生成，若重复自动加序号；并更新 `src/content/posts/_manifest.json`（含 slug、日期、tags、可用于生成列表页）。
- **图片管线**：封面或正文插图先放进 `assets/inbox/`，脚本用 `sharp` 重命名为 `slug-{locale}.jpg/webp`、去 EXIF、压缩，最后输出到 `public/images/blog/` 并把路径写回 frontmatter 的 `coverImage` /正文引用。
- **部署触发**：CLI 完成内容与静态资源写入后，自动运行 `pnpm lint && pnpm build` 验证，再选择：
  - 本地 `git add + git commit + git push`（由脚本执行 shell 命令），触发 Vercel；
  - 或直接 `vercel deploy --prod`。
  - 提供 `--dry-run` 以便只生成文件不部署。
- **一键命令**：`pnpm blog:publish --file content/drafts/my-article.md --auto-translate --deploy`，整套流程串起来实现“一键”。

## 模块拆分

| 模块 | 功能 | 实现要点 |
| - | - | - |
| `content-linter` | 解析原始 Markdown，校验必填字段、日期格式、标签合法性 | `gray-matter` + 自写规则 |
| `translator` | DeepSeek 翻译调度，支持并行 + 重试 + 术语表 | 环境变量存 API Key；先生成 en→目标语言的 prompt 模板 |
| `slug-manager` | 统一 slug 命名、查重 | 读取 manifest；按 `kebabCase(title)`，已有则 `-2` |
| `image-pipeline` | 上传图片自动命名、压缩、落地 | `sharp` + `exifr`; 生成 jpg+webp，返回路径 |
| `content-writer` | 生成多语言 md 文件 | frontmatter 模板 + markdown body |
| `manifest-builder` | 汇总所有 posts 的 metadata | 供列表页/站点地图、RSS 使用 |
| `deploy-runner` | 构建 & 发布 | 允许 `--skip-build`，默认执行 lint/build/deploy |

## 交互流程

1. 作者把原始 markdown + 图片放到 `content/drafts/`、`assets/inbox/`。
2. 运行 `pnpm blog:publish --file content/drafts/foo.md --auto-translate`.
3. CLI：
   - 解析 frontmatter，生成 slug。
   - 多线程调用 DeepSeek，拿到 8 份译文。
   - 处理图片，更新 frontmatter。
   - 写入 `src/content/posts/<locale>/<slug>.md`。
   - 更新 manifest / sitemap / RSS（若需要）。
4. 可选 `--deploy`：脚本自动 lint/build → git push 或 vercel deploy。
5. Vercel 构建后，列表页/详情页自动读取最新内容，无需手动改代码。

## 细节建议
- 翻译结果缓存到 `.cache/translations.json`，避免重复请求。
- 支持自定义语言列表（通过 CLI 参数或配置文件）以便扩展。
- CLI 输出详细日志和失败回滚（删除已写文件）。
- 在 CI 中引用同一个 CLI，保证本地/线上流程一致。
- 若后续要接收正文中的插图，可约定 `![alt](images/foo.png)` 这种相对路径，脚本扫描并自动搬运/改名。

这样，你只需要准备好主语言 Markdown 和图片，运行一条命令，就能完成多语言转换、资源整理、页面生成、部署发布的全流程自动化。
